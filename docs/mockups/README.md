# UI 시안 (구현 기준)

구현된 frontend 화면을 기준으로, 바뀔 부분만 그린 클릭 가능한 HTML 시안이다. 브라우저로 파일을 열면 된다(서버 불필요). 웹 폰트만 Google Fonts에서 불러온다.

| 파일 | 내용 | 관련 이슈 |
| --- | --- | --- |
| `round2-ui.html` | 2차: 운영 면담/회의실/교육과정, 교육생 홈/면담/회의실/도서/후기 | #148~#159 |
| `round3-ui.html` | 3차: 버튼·밀도 규격(공통), 교육생 홈/면담/도서/후기, 운영 면담/교육과정 | 3차 마일스톤 이슈 |
| `round4-ui.html` | 4차: 운영 면담 관리(설정 카드 폭·정렬)·도서 관리(탭 카드), 교육생 면담 신청(유동 폭 블록·호버 툴팁) | 4차 마일스톤 이슈 |

- 상단 버튼으로 화면(탭)을 고른다. 각 화면 위의 '변경점' 상자가 구현할 내용이다. 이슈 본문은 이 파일의 화면 이름을 참조한다.
- 3차 시안은 1440×900 / 1920×1080 크기로 축소해 보여주며, 오른쪽 위 배지가 '한 화면에 들어감'인지 스크롤이 필요한지 알려준다.
- `design/*.dc.html`은 개발계획서용 임시 시안이라 현재 화면과 달라 기준이 아니다.

## 시안 규칙 변경 이력
- 카드 높이: 한 행에 **나란히 놓인 카드만** 같은 높이로 맞춘다. 세로로 쌓인 카드는 내용 높이 그대로 둔다(2차 시안의 '마지막 카드를 늘리는' 동작은 폐기).
- 버튼(3차): 기본·보조·위험 3역할, 높이 36px/28px(모바일 44px), 글자는 항상 가로 한 줄.
